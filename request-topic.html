  1. Which guide did you read?
    你读了哪篇指南？可以填写文章标题。
  2. Was the guide easy to understand?
    这篇指南是否容易理解？如果还没读过，可以选择“I did not read a guide yet”。

    哪一段、哪个词或哪种说明让你不理解？

    你希望接下来增加什么主题？

    选择适合你的情况，例如在日本生活、准备来日、工作、学习或帮助他人。

    有哪些日语词语、表格、通知或文件需要说明？只写必要的非敏感内容，不要粘贴个人资料。

    还有其他意见吗？
